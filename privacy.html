二、使用范围与首次选择

本应用供班主任管理班级和课堂激励，学生不需要注册账号或自行操作。老师应依学校要求及适用规则取得录入、展示学生信息所需的授权，尽量使用学生昵称或编号，不录入身份证号、家庭住址等与功能无关的信息。

首次使用或本说明版本更新时，应用先显示原生说明页。明确点击“同意并继续”且同意记录成功保存后，才允许启动图鉴及班级功能、读取相应的本机记录。“不同意并退出”或在此页按系统返回键会退出，不清空、不修改已有班级存档。已同意的说明版本与同意时间保存在本机，用于再次打开时确认选择。

三、哪些内容在本机处理

本机还保存是否已完成首次宠物图鉴及图鉴版本号，用于首次引导和设置中的重新查看；这一记录不含学生资料，不随班级备份导出。首次图鉴展示宠物、成长与课堂激励的用途，不创建虚构班级或学生，不修改正式班级；完成首次图鉴后才读取正式班级记录。旧版使用教学的完成记录不能代替本版图鉴的完成记录。

老师录入的班级、学期、教师信息，学生姓名或昵称、学号或编号，作业要求、日期、完成及补交状态，考试、奖励记录与老师填写的期末名次，以及认养宠物、成长、徽章、收藏、寄语和日期等，保存在本应用的本机私有空间，用于显示、喂养、奖励和生成卡片。应用不自动获取学生成绩；如老师在名称、要求或备注等自由文本中填写成绩，这些文字也会随记录保存在本机。

电子成长卡可免费保存为图片。期末奖励卡可免费保存为 PDF、分享或打印。新版不使用安装标识或授权码发卡。

期末卡片 PDF 及最近最多 200 条生成记录保存在本机。记录包含所选学生、宠物、时间、文件名。旧版记录中可能保留当时填写的发放方式与价格。损坏存档救援会在本机私有空间保留最近一份损坏原文。

本应用没有联网权限，没有用户账号、广告、支付或自动云同步，不主动调用网络服务，不自动读取通讯录、位置、相机或麦克风。

四、导出、分享、打印与文件选择

你主动选择受支持的 Excel/WPS 学生表格后，应用在本机读取并解析其中的学生姓名或昵称、学号或编号，用于添加学生。该过程不调用服务器、不上传表格或学生资料；应用没有联网权限。请只选择已取得所需授权的表格，导入前核对姓名、编号及重复记录。

你主动导出的 JSON 备份包含班级、学生、作业、考试和成长信息。备份不包含卡片 PDF 及最近生成记录；卡片文件可另行保存。

你选择保存位置、分享对象、打印服务或导入图片与备份时，系统文件应用、网盘、分享应用或打印服务可能处理、保存、上传或转发这些文件，数据可能因此离开手机。这由你的操作和所选服务决定，不等于本应用自动上传。请先核对接收方、文件内容和服务规则，妥善保管学生信息。

你可以向运营者咨询可选的 6 英寸实体卡代制服务，每张 19.9 元，运费或整班合寄方式另行确认。点击邮件咨询或电话咨询会打开系统邮件应用或拨号界面，仅带入运营者的联系地址或电话号码。应用不自动发送学生信息，不自动附加卡片或发起付款。若你自行发送邮件、卡片或收件信息，所选服务和接收方将处理你主动提供的内容。

恢复备份会明确确认并替换当前全部班级。生成卡片只包含你选择的学生与卡片内容，不把考试成绩或名次印在卡片上。

五、保存、查阅与删除

你可在应用中查阅、更正班级记录，在“设置与备份”导出或恢复备份。请在卸载、清理应用数据或换手机前保存需要的备份。

卸载应用或通过系统清除应用存储，会删除本机私有的班级记录、损坏原文、卡片与生成记录、图鉴完成记录和同意记录。已导出到其他位置或已分享、打印的内容不会随应用卸载自动删除，需要你到对应位置或联系接收方处理。

本应用不提供联网账号和服务端删除入口。涉及资料更正、删除或其他疑问，可通过上方联系方式咨询。

六、重新查看与版本变化

同意后可随时在“设置与备份”或“使用说明”打开本离线说明。阅读不需要网络。若未来增加联网、账号、广告、支付或其他数据用途，应先更新说明和相应实现，再按实际适用要求征求选择；当前版本不包含这些服务。

公开体验与教师网页版

打开网页时

公开介绍页、六宠体验班、此政策及教师版下载由 GitHub Pages 提供。访问或下载时，浏览器向托管服务发出请求，服务可能处理用于交付内容和安全维护的 IP 地址与访问日志。详见 GitHub 隐私声明。

体验班与真实班级

公开体验班使用虚构昵称，供老师了解课堂流程。请勿在体验班录入真实学生资料。老师可在电脑上完整解压教师版后离线建班。班级和学期、学生姓名或昵称、编号、作业完成和补交情况、礼包、老师录入的名次、宠物及成长记录保存在当前浏览器。老师应按学校要求取得所需授权，尽量使用昵称或编号。

资料的查阅与保管

老师可在教师版查阅、更正班级资料，主动导出或恢复班级备份、保存成长卡和打印所选学生的珍藏卡。切换设备、浏览器或解压目录前，请先导出备份。清除对应浏览器存储可删除本机记录。已导出的备份、图片、PDF 和已发送的文件需分别删除。展示、分享、代印或导出前，请核对所选内容和接收对象。

自愿咨询实体卡

点击咨询邮箱或电话会打开所选邮件或拨号应用。网页不附带学生资料或卡面，也不自动下单、发送或付款。如自行提交卡面、联系方式或收件信息，所选服务及接收方将处理这些资料。请只提供办理该次业务必需的内容。
